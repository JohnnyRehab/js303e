js303

A true 303… in JavaScript

TB-303 clone using the Web Audio API. Original engine by Emil Loer (2014). This copy is a static rebuild: no Ruby, no server.

Press Run to start. Drag the knobs vertically. Click piano keys and the step buttons to program a pattern.
